# Awesome Free Browser Tools

> A curated list of free, browser-based tools that require no signup and run entirely client-side.

[![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

All tools on this list are:
- ✅ **100% Free** — no premium tier required for core functionality
- ✅ **No Signup** — use immediately, no account needed
- ✅ **Browser-Based** — runs entirely in your browser, no data uploaded to servers
- ✅ **Privacy-First** — your data never leaves your device

## Contributing

Contributions welcome! Please read the [contribution guidelines](CONTRIBUTING.md) first.

**To add a tool:**
1. The tool must be free with no mandatory signup for core functionality
2. The tool must run client-side (data stays in browser)
3. Add it to the correct category in a table row: `| [Tool Name](URL) | Brief description (1 sentence) | Source |`
4. Submit a pull request

**To suggest a tool:**
Open an issue with the label `tool-suggestion` and include the URL and why it qualifies.
